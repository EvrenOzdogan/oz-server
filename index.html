What makes it different

First person

A real city

Midtown Manhattan from OpenStreetMap data: the street grid, avenues and parks, 30-storey towers, working elevators, farmland and towns around it.

180+ curated mods: overhauled weather and lighting, immersive effects, vehicles, loot and crafting depth.

/sethome and /home, fast travel between waystones you have found, spawn selector, in-game rules panel and /help.

Fresh world

Build 42.21, 24/7 hosting, backups every 6 hours, active admin, Discord support.

How to join (5 minutes)

  1. Subscribe to the collection with one click ("Subscribe to all"): Oz Server Modpack. Let Steam finish downloading.
  2. Install ZombieBuddy once (the Java loader Project Viewpoint needs, not on the Workshop): ZombieBuddyInstaller.exe, choose Both. On first launch approve the Java mods.
  3. Join: Project Zomboid → Join → add server 208.75.182.159 port 28090. The password is in the Discord join channel.
  4. Optional: give the game more memory for the big city: in ProjectZomboid64.json change -Xmx3072m to -Xmx8g (16 GB RAM or more).

Controls: O first person · V aim · Q/E lean · hold crouch = prone · Space vault · Delete graphics. Requirements: Build 42.21, 6 GB+ VRAM (texture compression on below 12 GB), Windows or Linux. macOS and Intel Arc are not supported by Viewpoint.
