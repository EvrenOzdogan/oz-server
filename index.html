What makes it different

First person

Project Viewpoint: DayZ-style aiming and recoil, true ballistics, lean, prone and vault. HD floors, walls, cars, weapons and clothing, 3D trees, fences and props. Switch to third person or the classic top-down view any time (O).

A real city

Midtown Manhattan from OpenStreetMap data: the street grid, avenues and parks, a varied skyline topped by the 15-floor Empire State Building, working elevators, farmland and towns around it.

Deep survival

About 173 curated mods: overhauled weather and lighting, immersive effects, vehicles, rafts and swimming, loot and crafting depth.

PvP with rules

Safety toggle, factions, protected safehouses. 20 waystone beacons (with a teleport sound) mark PvP hot zones with supply drops.

Quality of life

/sethome and /home, fast travel between waystones you have found, 37 named spawn districts and towns, in-game rules panel and /help.

Fresh world

New world started Oct 16 afternoon (map 2.5.5); the old world is archived. Build 42.21, 24/7 hosting, backups every 6 hours, active admin, Discord support.

How to join (5 minutes)

  1. Subscribe to the collection with one click ("Subscribe to all"): Oz Server Modpack. Let Steam finish downloading (about 9 GB, best done the day before).
  2. Install ZombieBuddy once (the Java loader Project Viewpoint needs, not on the Workshop): ZombieBuddyInstaller.exe, choose Both. On first launch approve the Java mods.
  3. Join: Project Zomboid → Multiplayer → Add Server 208.75.182.159 port 28090. The join PIN is shown on the game's main menu. Pick a username and password for your account and press Connect. If a "Server Workshop Items" list appears, press Install and wait (the HD texture packs are about 1 GB). When ZombieBuddy shows its Java Mod Approval window, tick Allow on the rows that belong to the Oz Server's Workshop mods (the list; Java mods run with full rights on your PC, so leave anything you do not recognise unticked), tick "Save decisions" and press OK.
  4. Spawn: choose a Midtown district or a town on the map, make your character, play. The first load takes 2-3 minutes (173 mods); later ones are faster.
  5. Optional, same PC class as ours (RTX 4070/5070, 32 GB): download oz-viewpoint-settings.properties, rename it to viewpoint-live.properties and drop it into your Zomboid folder with the game closed. That applies our whole Viewpoint graphics setup (DLSS Quality, frame generation off, low latency on, sky on max).
  6. Optional, performance setup (Windows): the modded city needs a bigger Java heap and a few Windows GPU settings. Download oz_pc_tune.py (and oz_pz_profile.nip for NVIDIA cards), close the game, run python oz_pc_tune.py --dry-run and read the table of current vs recommended values. To apply, run python oz_pc_tune.py (as Administrator to include GPU scheduling) and type YES yourself; it backs up every file it changes and python oz_pc_tune.py --undo restores them.
    By hand: in Steam\steamapps\common\ProjectZomboid\ProjectZomboid64.json set -Xmx to 12g (32 GB RAM), 10g (24 GB) or 8g (16 GB; expect stutter, 16 GB PCs will struggle); do not go below 11g on 32 GB because the modded server peaks near 10.5 GB of heap. Windows Settings > System > Display > Graphics: turn on Hardware-accelerated GPU scheduling (reboot) and add ProjectZomboid64.exe with High performance. NVIDIA: with NVIDIA Profile Inspector run nvidiaProfileInspector.exe -silentImport oz_pz_profile.nip (max performance power mode, threaded optimization on). Steam "Verify integrity of game files" resets the json, so redo the heap after it.
