How to join (5 minutes)

  1. Game version first. In Steam: right-click Project Zomboid > Properties > Game Versions & Betas > Default Public Version (Project Zomboid 42.22.2). Then Installed Files > Verify integrity of game files. Do this BEFORE step 2.
  2. Install the Project Viewpoint 0.1.7-rc4 nightly. Get Viewpoint-nightly-0.1.7-rc4.zip from the Project Viewpoint Discord (#nightly-access) and follow its install steps. Use rc4 exactly. The Steam version of Viewpoint (0.1.6.x) cannot join. The zip the server was built against has SHA-256 4f42cdcbe0452d16f205efa71066c9fff0b99e58a7de4adfe81d14978a8b5456 (check with certutil -hashfile Viewpoint-nightly-0.1.7-rc4.zip SHA256); do not install a file that does not match.
  3. Subscribe to the collection with one click ("Subscribe to all"): Oz Server Modpack. Let Steam finish downloading.
  4. Join: start the game and close the Viewpoint first-run setup without changing anything. Multiplayer > Add Server 208.75.182.159 port 28090, no password. On your first join, click a spawn icon on the map.
  5. Optional, performance setup (Windows): the modded city needs a bigger Java heap and a few Windows GPU settings. Download oz_pc_tune.py (and oz_pz_profile.nip for NVIDIA cards), close the game, run python oz_pc_tune.py --dry-run and read the table of current vs recommended values. To apply, run python oz_pc_tune.py (as Administrator to include GPU scheduling) and type YES yourself; it backs up every file it changes and python oz_pc_tune.py --undo restores them.
    By hand: in Steam\steamapps\common\ProjectZomboid\ProjectZomboid64.json set -Xmx to 8g (the same value the script writes; on a 16 GB PC expect stutter, most of the game's memory is outside the Java heap). Windows Settings > System > Display > Graphics: turn on Hardware-accelerated GPU scheduling (reboot) and add ProjectZomboid64.exe with High performance. NVIDIA: with NVIDIA Profile Inspector run nvidiaProfileInspector.exe -silentImport oz_pz_profile.nip (max performance power mode, threaded optimization on). Steam "Verify integrity of game files" resets the json, so redo the heap after it.

ZombieBuddy (the Java loader Viewpoint needs): if it is not set up on your PC yet, run ZombieBuddyInstaller.exe and choose Both. If loading seems to pause, alt-tab: ZombieBuddy may be asking you to approve a mod (the list of Oz Workshop Java mods; Java mods run with full rights on your PC, so leave anything you do not recognise unticked). Tick Allow, then OK.

If the join fails with "server failed to respond" right after an Oz update, let Steam finish downloading and try again a few minutes later.

Crash on load? Unsubscribe from "Project Viewpoint - Actual Door Rattling" and "Visceral Viewpoint"; both break Viewpoint 0.1.7. For any other crash, send your Zomboid\console.txt on the Discord.
